The Decision Matrix

좋은 결과가 항상 좋은 판단은 아닙니다

Skill (역량)

좋은 판단 × 좋은 결과

철저한 근거와 명확한 전제로 기대치를 달성한 성공 사례. 조직의 핵심 플레이북으로 내재화합니다.

Bad Break (불운)

좋은 판단 × 나쁜 결과

당시 정보 수준에서 최선의 선택이었으나 예상치 못한 외생 변수로 실패한 사례. 담당자를 비난하지 않고 전제를 갱신합니다.

Dumb Luck (요행)

나쁜 판단 × 좋은 결과

근거와 전제가 빈약했으나 운 좋게 성공한 사례. 재현 불가능한 성공에 도취되는 것을 방지합니다.

Mistake (오판)

나쁜 판단 × 나쁜 결과

전제 오류와 확신 과잉으로 발생한 오판. 당시 어떤 신호를 놓쳤는지 AI와 함께 회고하여 학습합니다.

01 · STRUCTURED REASONING

5단계 가이드로 완성하는
의사결정의 뼈대

산발적인 회의록 대신, 판단에 꼭 필요한 5가지 핵심 요소를 단계별로 기록합니다.

  • ✓ Decision: 결론과 실행 지침의 명확한 정의
  • ✓ Why & Assumptions: 숨은 전제와 기각된 대안(Alternatives) 보존
  • ✓ Known_at Evidence: 정보의 생성일이 아닌 '내가 알게 된 시점' 기록
  • ✓ Invalidation Signal: 이 판단이 틀렸음을 입증할 반증 기준 사전 선언
  • ✓ Confidence Gauge: 기록 당시의 주관적 확신도(0~100%) 보존

02 · TIME TRAVEL REPLAY

미래 정보를 제거하고
당시의 눈으로 다시 봅니다

Time Slider를 움직이면 사후에 알게 된 결과와 증거가 그래프에서 완전히 필터링됩니다. 당시 알고 있던 정보만으로 과거의 나를 마주하세요.

  • ✓ Mathematical Filtering: known_at > replay_time인 미래 노드 완벽 차단
  • ✓ Then vs Now: 당시의 기대치와 현재의 실제 성과 비교
  • ✓ AI Historical Review: 과거 시점 컨텍스트 기반 LLM 객관성 검토

03 · DECISION INTELLIGENCE

개인과 조직의 사고 습관을
데이터로 분석합니다

시간이 흐를수록 축적되는 의사결정 데이터를 통해, 나의 확신도가 실제 결과와 얼마나 일치하는지 교정(Calibration)할 수 있습니다.

  • ✓ 평균 확신도 및 근거 깊이(Evidence Depth) 추적
  • ✓ Skill vs Luck 사분면 매트릭스 실시간 집계
  • ✓ 팀장 승인 및 다자간 검토 워크플로우 통합

Ready to deploy?

30초 만에 로컬에서 실행하기

bash · quickstart.sh
# 1. PostgreSQL 컨테이너 실행
docker run -d --name trace-db -p 5432:5432 -e POSTGRES_USER=trace -e POSTGRES_PASSWORD=password -e POSTGRES_DB=trace postgres:16-alpine

# 2. 필수 환경변수 설정 (정확히 4개)
export POSTGRES_DSN='postgres://trace:password@127.0.0.1:5432/trace?sslmode=disable'
export BOOTSTRAP_ADMIN='admin@example.internal'
export BOOTSTRAP_ADMIN_PASSWORD='a-long-bootstrap-password'
export ENCRYPTION_KEY="$(openssl rand -base64 32)"

# 3. Trace 서비스 빌드 및 실행
./trace

# 4. 브라우저에서 http://localhost:8080 접속!
