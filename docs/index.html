Core Methodology

결과 편향을 배제하는 판단 보존 철학

좋은 판단이 항상 좋은 결과를 보장하지 않으며, 나쁜 결과가 나쁜 판단을 의미하지 않습니다.

⏱️

Time Travel Replay

특정 과거 시점으로 슬라이더를 되돌려, 사후 결과를 배제한 채 당시의 지식 상태만으로 판단 품질을 복기합니다.

🧩

5-Step Structuring

Decision -> Why & Assumptions -> Probabilities -> Milestones -> Lock으로 이어지는 5단계 사고 프레임워크.

📊

Calibration Analytics

Brier Score와 보정 곡선을 통해 예측 확률과 실제 적중률 간의 캘리브레이션 오차를 정량 분석합니다.

🔐

AES-256 Envelope Encryption

사용자별 독립 데이터 키로 암호화되며, 단일 ACID 트랜잭션 내에서 무중단 실시간 키 회전을 지원합니다.

🛡️

Enterprise Approvals

중요 의사결정의 사전 검토 및 승인 대기열 거버넌스와 변조 불가한 감사 로그(Audit Log)를 제공합니다.

📦

Offline Air-Gapped Monolith

Go 단일 바이너리에 React 19 SPA를 완벽 임베딩하여 인터넷이 없는 폐쇄망 환경에서도 100% 자립 구동됩니다.

Frequently Asked Questions

자주 묻는 질문 (FAQ)

Trace의 핵심 기능, 타임 트래블 리플레이 및 보안에 대한 안내입니다.

Trace는 기존 문서나 위키와 무엇이 다른가요?
일반적인 위키나 문서는 사후에 수정될 수 있어, 결과가 나쁘면 과거의 판단 논리까지 왜곡되거나 잊혀집니다. Trace는 결정 당시 알고 있던 정보(전제, 기각된 대안, 기대 확률)를 불변으로 잠그고, 사후 결과와 엄격히 분리 기록하여 결과 편향 없이 당시 판단 프로세스의 본질적 품질을 복기할 수 있게 합니다.
타임 트래블 리플레이(Time Travel Replay)는 어떻게 동작하나요?
의사결정 상세 화면에서 타임라인 슬라이더를 과거 특정 날짜로 이동하면, 그 이후에 발생한 실제 결과나 회고 내용이 완벽하게 마스킹됩니다. 평가자는 당시 결정자가 보았던 정보만을 바탕으로 시뮬레이션할 수 있어 사후 확신 편향 없는 공정한 피드백이 가능합니다.
조직의 민감한 의사결정 데이터는 어떻게 암호화되나요?
Trace는 2계층 봉투 암호화(AES-256-GCM Envelope Encryption)를 적용합니다. 각 사용자마다 독립적인 데이터 키(DEK)로 암호화되며, 단일 PostgreSQL ACID 트랜잭션 내에서 서비스 중단 없이 실시간으로 키를 재암호화하는 무중단 키 회전(Zero-Downtime Key Rotation)을 지원합니다.
폐쇄망(Air-Gapped) 환경에서도 배포 및 구동이 가능한가요?
네, 100% 완전 오프라인 구동을 보장합니다. Go 단일 실행 파일 내에 React 19 정적 에셋이 임베딩되어 있어 외부 네트워크 통신이 전혀 필요 없습니다. PostgreSQL 16+ 컨테이너와 4개의 필수 환경변수만 설정하면 즉시 완벽하게 동작합니다.
조직 모드에서 승인(Approvals) 거버넌스는 어떻게 운영되나요?
관리자가 승인 정책을 활성화하면, 팀원이 등록한 중요 의사결정은 즉시 [검토 및 승인] 대기열로 이동합니다. 팀장은 결정 논리와 위험 분류를 검토한 후 단 한 번의 클릭으로 승인하거나 피드백과 함께 반려할 수 있습니다.

30초 만에 로컬에서 실행하기

단 4개의 환경변수로 안전한 Decision Intelligence 플랫폼을 기동하세요.

bash · quickstart.sh
# 1. PostgreSQL 컨테이너 실행
docker run -d --name trace-db -p 5432:5432 -e POSTGRES_USER=trace -e POSTGRES_PASSWORD=trace -e POSTGRES_DB=trace postgres:16-alpine

# 2. 필수 환경변수 설정 (정확히 4개)
export DATABASE_URL='postgresql://trace:trace@127.0.0.1:5432/trace?sslmode=disable'
export BOOTSTRAP_ADMIN='admin@example.internal'
export BOOTSTRAP_ADMIN_PASSWORD='a-long-bootstrap-password'
export ENCRYPTION_KEY="$(openssl rand -base64 32)"

# 3. Trace 서비스 빌드 및 실행
./trace

# 4. 브라우저에서 http://localhost:8080 접속!
